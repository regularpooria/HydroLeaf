# Contributing to CanopyMap

## Onboarding checklist

1. Read `/README.md` to understand the project objective.
2. Read `/docs/onboarding/repo.md` to learn repository layout.
3. Choose your area (`segmentation`, `tracking`, or `deployment`) and review the matching docs under `/docs`.
4. Implement code in the corresponding `/src` directory.

## Working style

- Keep pull requests focused and small.
- Update docs when adding or changing behavior.
- Avoid mixing unrelated refactors with functional changes.
